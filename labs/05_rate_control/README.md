# Lab 05: Rate Controller (角速度內環 PID 控制器與混控器)

## 1. Lab 目標與設計理念

在多旋翼無人機控制架構中，「角速度環（Rate Loop）」是**最核心、頻率最高（通常 250Hz ~ 1000Hz）、決定飛行穩定性的最內層迴路**。
**設計金律：在角速度環調試好之前，絕對不要開始調角度環（Attitude Loop）！**

### 核心回授迴路架構
```
  rate_sp (目標角速度)
         │
         ▼   +
       ( Σ ) ───> [ PID 控制器 ] ───> torque (力矩) ───> [ 混控器 Mixer ] ───> 馬達輸出 [0~1]
         ▲   -                                                                       │
         │                                                                           ▼
         └────────────── gyro (陀螺儀實際角速度) ◀───────────── [ 物理模擬器 / 四旋翼 ]
```

---

## 2. PX4 控制演算法核心要素

1. **誤差定義**：$e = \omega_{sp} - \omega$
2. **比例項 (P)**：提供瞬態剛性響應，迅速產生糾正力矩。
3. **積分項 (I)**：消除機體質量分佈不均、微風干擾造成的穩態誤差。
   - 必須具備**抗積分飽和（Anti-Windup）**，限制積分累積上限。
4. **微分項 (D)**：提供系統阻尼，抑制超調與振盪。
   - 陀螺儀高頻噪聲會被微分放大，因此 D 項必須經過**一階低通濾波器（Low-pass Filter）**。
5. **混控矩陣 (Control Allocator / Mixer)**：
   將三軸力矩 $[\tau_x, \tau_y, \tau_z]$ 與總油門 $T_{thrust}$ 解耦分配為四個馬達的獨立轉速 $[m_1, m_2, m_3, m_4]$。

## 3. 三個實現階段說明

### 階段一：基礎版（Stage 1 - 基礎角速度 PID 控制器）
- **重點**：實作純數學 PID 演算法，完成單元測試。
- **驗證項目**：
  - Test A: 誤差為 0 時，輸出接近 0。
  - Test B: 目標角速度 +1.0 rad/s, 當前為 0 時，輸出正向滾轉力矩。

### 階段二：核心進階版（Stage 2 - 工業級防護與濾波）
- **重點**：實現抗飽和積分（Anti-Windup）、D 項低通濾波、輸出限幅、NaN/Inf 防護、無效 dt 攔截。
- **驗證項目**：
  - 驗證長時間誤差下積分器不會無限累積。
  - 驗證遭遇 NaN 輸入時控制器安全降級回傳 0，避免整機失控。

### 階段三：PX4 對標進階版（Stage 3 - 混控器與閉迴路步階響應）
- **重點**：串聯 Lab 04 的 6-DOF 四旋翼模擬器，構成真正完整的角速度閉迴路控制系統。
- **整合項目**：
  - 實作 X-Frame Mixer 混控演算法。
  - 給定滾轉角速度階躍命令：`roll_rate_sp = +1.0 rad/s`。
  - 運行 1 秒，驗證無人機角速度平穩追隨目標值並收斂至 $1.0 \pm 0.05 \text{ rad/s}$。
