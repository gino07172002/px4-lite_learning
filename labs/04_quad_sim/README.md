# Lab 04: Quad Physics Simulator (四旋翼物理動力學模擬器)

## 1. Lab 目標與設計理念

在飛控演算法（PID、卡爾曼濾波、姿態估計）寫入韌體前，必須有一個獨立、純粹的**物理動力學模擬器**。
**最核心原則：本 Lab 嚴禁加入任何 PID 或回授控制器！**
這是一個「開放迴路（Open-Loop）」的受控體（Plant Model）。

我們只驗證物理定律與座標變換的正確性：
```
[馬達控制量 0~1] ──> [升力與力矩計算] ──> [牛頓/歐拉運動方程] ──> [加速度/角速度] ──> [位置/姿態]
```

---

## 2. 座標系與四旋翼 X 機型定義 (Standard Quad X)

### 座標系：NED (North-East-Down) 或機體座標 FRD (Forward-Right-Down)
- **X 軸**：機頭朝前 (Forward)
- **Y 軸**：右側機臂 (Right)
- **Z 軸**：垂直朝下 (Down)
- **Roll (滾轉)**：繞 X 軸，右傾為正 (+)
- **Pitch (俯仰)**：繞 Y 軸，抬頭為正 (+)
- **Yaw (偏航)**：繞 Z 軸，順時針為正 (+)

### 四旋翼 X 架構馬達配置 (對標 PX4 Quad X):
```
       前 (Forward +X)
      M3(CCW)    M1(CW)
          \    /
           \  /
            ><
           /  \
          /    \
      M2(CW)    M4(CCW)
       後 (Back -X)
```
- 機臂長度 $L$、馬達推力係數 $k_t$、反扭矩係數 $k_m$。
- **滾轉力矩 ($\tau_x$)**：由左右馬達推力差產生。
- **俯仰力矩 ($\tau_y$)**：由前後馬達推力差產生。
- **偏航力矩 ($\tau_z$)**：由順時針(CW)與逆時針(CCW)旋轉的反扭力差產生。

## 3. 三個實現階段說明

### 階段一：基礎版（Stage 1 - 1-DOF 垂直升降動力學）
- **重點**：掌握牛頓第二運動定律數值積分。
- **物理方程**：$a_z = \frac{\sum T_i}{m} - g$。
- **驗證**：
  - 總升力 > 重力時，飛機加速上升。
  - 總升力 < 重力時，飛機向下墜落。
  - 懸停油門時加速度為 0。

### 階段二：核心進階版（Stage 2 - 6-DOF 剛體動力學）
- **重點**：實現完整的 6 自由度三維力矩與歐拉角姿態積分。
- **物理方程**：
  - 轉動慣量張量 $I_{xx}, I_{yy}, I_{zz}$。
  - $\dot{\omega} = I^{-1} (\tau - \omega \times (I\omega))$。
- **驗證項目**：
  - Case 1: 4 個馬達輸出均等 -> 力矩 $\tau \approx 0$，姿態不轉動。
  - Case 2: 左側馬達推力大、右側馬達推力小 -> 產生正滾轉力矩（向右傾斜）。

### 階段三：PX4 對標進階版（Stage 3 - 馬達延遲濾波與感測器噪聲）
- **重點**：對標真實物理環境與 SITL 感測器模擬。
- **機制**：
  - **馬達一階時間常數延遲（Motor Lag）**：馬達無法瞬間達到設定轉速，模擬真實電調與轉子慣性。
  - **合成 IMU 感測器模型**：加入高斯噪聲（Gaussian Noise）與零偏漂移（Gyro Bias）。
  - **確定性單元測試（Deterministic Test）**：驗證相同輸入與步長下，輸出精確可重現。

## 4. 驗收標準與測試清單

- [x] 四旋翼馬達推力對稱時，三軸力矩皆為 0。
- [x] 不對稱馬達輸出時，Roll/Pitch/Yaw 轉動方向嚴格符合右手法則與 FRD 座標系。
- [x] 推力大於重力上升，小於重力下降。
- [x] 同一輸入序列重跑兩次，輸出數值位元完全相同（Deterministic）。
