Lab 02：WorkQueue / Scheduler

executable：





workqueue_demo

這時可以 link Lab01 的 library，但其實不一定需要 TopicBus。

目標

回答：

為什麼 PX4 不需要每個 module 一個 thread？

架構：





                 Worker Thread
                      │
        ┌─────────────┼──────────────┐
        ▼             ▼              ▼
    IMU Task      Control Task    Logger Task

    100 Hz          50 Hz          10 Hz

做兩個 queue





HIGH
LOW

例如：





HIGH THREAD

FastTask      250Hz
MediumTask    100Hz


LOW THREAD

SlowTask       10Hz
Logger         20Hz

API





class WorkItem {
public:
    virtual void Run() = 0;
};

再做：





ScheduleNow();
ScheduleDelayed();
ScheduleOnInterval();
ScheduleClear();

Lab 02 驗收

執行：





./workqueue_demo

例如 10 秒後：





FastTask:
 expected = 2500
 actual   = 2498

MediumTask:
 expected = 1000
 actual   = 999

SlowTask:
 expected = 100
 actual   = 100

並且：





threads = 2
work items = 4

而不是：





threads = 4

額外實驗

故意：





void SlowTask::Run()
{
    sleep(1);
}

看看同 WorkQueue 上其他 task 發生什麼事。

你會非常直觀理解：

WorkQueue 上任何一個工作 blocking，都會拖累共用該 queue 的其他工作。

這會是很好的面試題。
